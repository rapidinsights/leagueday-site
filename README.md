# LeagueDay site

The marketing site for [LeagueDay](https://leaguedaygolf.com), golf league management for public courses.

Built with [Astro](https://astro.build) and Tailwind CSS on the [AstroWind](https://github.com/arthelokyo/astrowind) template, hosted on Netlify.

## Develop

Requires Node 22.22.3 or later and pnpm.

```sh
pnpm install
pnpm dev      # local dev server at localhost:4321
pnpm check    # type check, lint, formatting
pnpm build    # static build to dist/
```
